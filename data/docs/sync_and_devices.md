# Syncing and Devices

The Lumen Drive desktop app is available for Windows 10 and later, macOS 12 and later, and Ubuntu 22.04 and later. Mobile apps are available for iOS 16+ and Android 11+.

Selective sync lets you choose which folders are downloaded to a computer. Files you do not select stay in the cloud and do not use local disk space. Turn it on in the desktop app under Preferences > Sync > Choose folders.

Smart Files (files on demand) shows every file in your file explorer but only downloads a file when you open it. Smart Files is available on Plus and Business plans only.

The maximum single file size is 50 GB through the desktop app and 2 GB through the web browser upload.

Sync conflicts: if the same file is edited on two devices while offline, Lumen Drive keeps both versions. The second copy is renamed with "(conflicted copy)" and the device name and date added to the file name.

To remove a lost or stolen device, go to Settings > Security > Devices and click "Unlink". On Plus and Business plans you can also choose "Remote wipe", which deletes the Lumen Drive folder from that device the next time it comes online.

Bandwidth limits can be set in Preferences > Network. By default, upload speed is limited automatically to 75% of available bandwidth so other apps stay responsive.
